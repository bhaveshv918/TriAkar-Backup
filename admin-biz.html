How to get the report files
📦 Amazon
  1. Seller Central → Reports → Fulfillment
  2. Or: Business Reports → Orders → By ASIN
  3. Download as CSV
  4. Key columns: order-id, purchase-date, sku, quantity, item-price, shipping-city
🛍️ Flipkart
  1. Seller Hub → Reports → Order Report
  2. Select date range → Download
  3. Key columns: Order ID, Order Date, SKU ID, Product Title, Quantity, Selling Price, City

How label import works
  1. Every day when you print labels, also upload the label PDF here
  2. The system reads each page as one label and extracts the order ID + customer address
  3. Set the default product + selling price (saves time if most orders are the same product)
  4. Review the table — edit any row that needs changes — then hit Import
  5. Orders are created in your Sales log automatically
Tip: If PDF extraction doesn't work well for your label format, use "Paste label text" — open the PDF in any viewer, select all text, paste here.
